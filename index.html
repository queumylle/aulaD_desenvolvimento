Desafio #01 Iniciante

Consumo da API ViaCEP com Async/Await

Crie um formulário HTML onde o usuário digita o CEP e, ao sair do campo (`blur`), os campos de Rua, Bairro e Cidade são preenchidos automaticamente.

async function buscarCEP(cep) {

// Tratar sanitização

const res = await fetch(`https://viacep.com.br/ws/${cep}/json/`);

const data = await res.json();

document.getElementById('rua').value = data.logradouro;

}

Implemente um campo de busca que escuta o evento `input` e filtra dinamicamente uma lista de elementos HTML sem recarregar a página.
